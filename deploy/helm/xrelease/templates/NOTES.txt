Wait for the rollout:

  kubectl -n {{ .Release.Namespace }} rollout status deploy/{{ include "xrelease.fullname" . }}

    kubectl -n {{ $.Values.networkPolicy.ingressControllerNamespace }} get svc

{{- range .Values.gateway.hostnames }}

  Routed through Gateway "{{ .Values.gateway.parentRef.name }}"{{ with .Values.gateway.parentRef.namespace }} in namespace {{ . }}{{ end }}.
  Confirm the route bound (Accepted=True and ResolvedRefs=True):
    kubectl -n {{ .Release.Namespace }} describe httproute {{ include "xrelease.fullname" . }}
  Gateway address:
    kubectl -n {{ .Values.gateway.parentRef.namespace | default .Release.Namespace }} get gateway {{ .Values.gateway.parentRef.name }}
{{- else }}

No front door configured — reach the UI with a port-forward:

  kubectl -n {{ .Release.Namespace }} port-forward svc/{{ include "xrelease.fullname" . }}-ui {{ .Values.ui.service.port }}
{{- end }}

{{- if and .Values.ui.enabled (eq (default "local" .Values.ui.env.VITE_AUTH_MODE) "local") }}

Sign in as {{ .Values.secrets.adminUser | default "admin" }} with the password
you passed in secrets.adminPassword.
{{- end }}

{{- if eq (include "xrelease.createSecret" .) "true" }}

The API key, webhook secret, session secret and config encryption key were
generated for you and are kept across upgrades. Read one back:

  kubectl -n {{ .Release.Namespace }} get secret {{ include "xrelease.secretsName" . }} \
    -o jsonpath='{.data.XRELEASE_API_KEY}' | base64 -d
{{- end }}

The instance starts idle. Author desired state in Config → Apply, or push it:

{{- if .Values.ingress.enabled }}
{{- with (first .Values.ingress.hosts) }}
  xrctl --api-url http://{{ .host }} --api-key "$XRELEASE_API_KEY" apply app/releases.yaml
{{- end }}
{{- else if .Values.gateway.enabled }}
{{- with (first .Values.gateway.hostnames) }}
  xrctl --api-url http://{{ . }} --api-key "$XRELEASE_API_KEY" apply app/releases.yaml
{{- end }}
{{- else }}
  xrctl --api-url http://127.0.0.1:{{ .Values.ui.service.port }} --api-key "$XRELEASE_API_KEY" apply app/releases.yaml
{{- end }}

Checks:

  kubectl -n {{ .Release.Namespace }} get pods -l app.kubernetes.io/instance={{ .Release.Name }}
  kubectl -n {{ .Release.Namespace }} logs deploy/{{ include "xrelease.fullname" . }}

{{- if not .Values.metrics.serviceMonitor.enabled }}

Metrics: /metrics is served by the backend Service on port {{ .Values.service.port }}
and is NOT published through the front door (it needs no auth). Enable
metrics.serviceMonitor.enabled=true for Prometheus Operator, or set
ui.exposeMetrics=true on a trusted network to restore the dashboard button.
{{- end }}

{{- if and .Values.postgresql.enabled .Values.postgresql.persistence.enabled .Values.postgresql.persistence.retain }}

The PostgreSQL PVC ({{ include "xrelease.postgresqlName" . }}) is annotated
helm.sh/resource-policy=keep — `helm uninstall` leaves the data behind.
Delete it explicitly to reclaim the volume.

This StatefulSet is a single replica with no backups — lab only. Switch with
postgresql.mode=cnpg (chart default) or an external managed database.
